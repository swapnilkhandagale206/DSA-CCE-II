# Music Playlist Manager

## Data Structures and Algorithms - CCE

### Objective
To implement a Music Playlist Manager using a Doubly Linked List in C++.

### Features
1. Add Song
2. Delete Song
3. Display Playlist
4. Display Playlist in Reverse
5. Play Current Song
6. Play Next Song
7. Play Previous Song
8. Play Complete Playlist
9. Repeat All
10. Show Current Song
11. Exit

### Data Structure
Doubly Linked List

### Programming Language
C++

### Concepts Used
- Classes and Objects
- Dynamic Memory Allocation
- Doubly Linked List
- Pointers
- Insertion and Deletion
- Forward and Reverse Traversal
- Menu-driven Programming
